# 手写数字识别 (1和7)

这是一个简单的手写数字识别系统，专门用于识别数字1和7。系统使用5x3的二进制矩阵来表示数字，并能识别多种不同的手写变体。

## 项目结构

```
.
├── main.py                     # 主程序文件，包含识别逻辑
├── number_patterns.py          # 数字模式定义文件
├── test_number_recognition.py  # 测试用例
└── show_test_cases.py         # 测试用例可视化工具
```

## 功能特点

- 支持5x3矩阵的数字识别
- 可识别数字1和7的多种手写变体
- 包含详细的测试用例
- 提供直观的格子图显示功能

### 支持的数字1变体

- 标准竖直的1
- 左/中/右对齐的1
- 不同位置的短1（上/中/下）
- 带左横和底座的1
- 斜体的1

### 支持的数字7变体

- 标准的7
- 斜体的7
- 弯折的7
- 尖锐的7
- 竖直的7
- 不同位置的短7

## 使用方法

1. 运行测试：
```bash
python -m unittest test_number_recognition.py
```

2. 查看所有测试用例的可视化效果：
```bash
python show_test_cases.py
```

3. 运行主程序：
```bash
python main.py
```

## 识别算法

系统使用模式匹配算法进行数字识别：
1. 计算输入与预定义模式的整体匹配度
2. 特别关注数字笔画（值为1的位置）的匹配情况
3. 综合考虑整体匹配度和笔画匹配度进行判断

## 开发说明

- 使用Python 3开发
- 不依赖外部库
- 使用单元测试确保识别准确性
- 提供直观的格子图显示功能便于调试
